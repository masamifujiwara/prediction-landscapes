## Project Directory Structure

All R scripts must be saved in `01_Analysis/`. The project root is the parent folder of `01_Analysis/`. Results are written by each script into `02_Results/` under subfolders named after the script.

```
<Project Root>/
├── 01_Analysis/               # All R scripts and data go here
│   ├── a_getdata.R
│   ├── b1_setup_paths_packages.R
│   ├── b3_ … .R
│   ├── … (all other *.R files)
│   ├── Data.RData             # Prepared input data object
│   ├── PATHS.RData            # Generated by b1; machine-specific absolute paths
│   ├── Data/                  # Intermediate data outputs (generated by scripts)
│   └── Logs/                  # Session logs (generated by scripts)
│
└── 02_Results/
    ├── 01_Figures/            # Figure outputs, one subfolder per script
    ├── 02_Tables/             # Table outputs, one subfolder per script
    ├── 03_Diagnostics/        # Diagnostic outputs, one subfolder per script
    └── 04_Models/             # Fitted model objects, one subfolder per script
```

## R Scripts

### Execution Order

Scripts are named alphanumerically and **must be run in alphanumerical order**, with one exception:

- **Figure scripts** (`fig*.R`) and **table scripts** (`tab*.R`) must be run **after all other scripts** have been completed, as they depend on outputs from the analysis pipeline.

### Running on a New Computer

1. Place all R scripts and `Data.RData` in the same folder (`01_Analysis/`).
2. Recreate the `02_Results/` folder structure at the same level as `01_Analysis/` (see diagram above), or allow `b1` to create it.
3. **Run `b1_setup_paths_packages.R` first.** This script detects the absolute path of the current machine and saves it to `PATHS.RData`, which is loaded by all subsequent scripts. Skipping this step will cause all downstream scripts to fail.
4. If transferring a partially completed analysis from another computer, copy all intermediate results into the same relative directory locations before resuming.

### Parallel Computing

Many scripts use parallel computing. The number of cores may need to be adjusted to match the available hardware on your machine.

### Operating System

Scripts were developed and run on both **Windows** and **Linux**. Some scripts may only function on one operating system, as each was typically run once on a single machine during the original analysis.

### Script Headers and Annotations

Each script includes a header describing its purpose along with its input and output files. The headers and some inline annotations were generated with the assistance of ChatGPT and **were not carefully reviewed for accuracy**. Please refer to the code itself as the authoritative source. Some exploratory analysis and debugging code remains in the scripts. The scripts are the **exact code used for the published calculations**; no changes have been made.

### Data

The raw data download and initial processing are documented in `a_getdata.R`. This script is **not intended to be rerun** by users, as it depends on the original local data environment and file paths. The prepared data object `Data.RData` is provided directly and serves as the starting point for the analysis workflow.
